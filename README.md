# 영화 추천 및 통계 분석 시스템 (Movie Recommendation & Statistics System)

본 프로젝트는 숭실대학교 컴퓨터학부 객체지향프로그래밍(CSE2150) 과목의 M4 최종 결과물입니다. 다형성 기반의 매니저 아키텍처를 도입하여 유저, 영화, 평점 데이터를 효율적으로 관리하고, 대용량 데이터 확장성을 고려한 정렬 알고리즘 및 복합 데이터 통계 리포트 추출 기능을 제공합니다.

## 1. 작성자 및 개발 환경
* **작성자**: 컴퓨터학부 강지웅
* **개발 언어 및 표준**: C++11 / C++17
* **컴파일러**: g++ (Ubuntu/WSL 환경)
* **빌드 도구**: GNU Make

## 2. 주요 기능 (Main Features)
* **영화 데이터 관리**: 신규 영화 등록, 제목 기반 검색, 전체 영화 목록 출력
* **사용자 데이터 관리**: 신규 사용자 등록, 전체 사용자 목록 출력
* **평점 및 추천 시스템**: 영화별 평점 실시간 누적 반영 및 피드백, 사용자 간 데이터 기반 맞춤형 영화 추천 알고리즘 수행
* **데이터 영구 보존**: 프로그램 시작 시 CSV 파일 데이터 파싱 및 로드, 프로그램 정상 종료 시 모든 변경 사항을 원본 CSV 파일에 영구 덮어쓰기

## 3. 클래스 구조 및 아키텍처 (Class Structure)
본 시스템은 12~13주차 핵심 이론인 **상속과 다형성(Polymorphism)**을 시스템 전체 구조에 적용했습니다.

* **BaseManager (추상 클래스)**: 파일 입출력인 `loadFromFile()` 및 `saveToFile()` 인터페이스를 순수 가상 함수(`virtual`)로 정의하여 다형성의 뼈대를 형성합니다.
* **UserManager / MovieManager / RatingManager**: `BaseManager`를 상속받아 각 데이터 특성에 맞게 파일 읽기/쓰기 로직을 오버라이딩(`override`)하여 다형성을 실현합니다.
* **Recommender**: 매니저 클래스들과 느슨한 결합(Loose Coupling)을 유지하며 맞춤형 영화 추천 연산을 전담합니다.
* **Data Classes (User, Movie, Rating)**: 각 데이터의 속성을 private 멤버 변수로 캡슐화하고 고유한 책임을 수행합니다.

## 4. M4 단계 핵심 확장 기능 (Extended Features)
강의 요구사항 및 가이드라인에 맞추어 시스템 안정성을 높이고 알고리즘을 다각화한 확장 기능 2가지를 추가로 구현했습니다.

### ① 모던 C++ 람다 함수(Lambda) 기반 한국어 가나다순 정렬 가공 (5번 메뉴)
* 단순 단일 정렬 구조를 탈피하여, 사용자의 선택에 따라 동적으로 정렬 기준을 바꿀 수 있도록 `std::sort`와 **모던 C++ 람다 식**을 결합했습니다.
* 내부 `Movie` 객체의 `title` 문자열(Getter)을 람다 캡처 구조 내에서 직접 비교 연산하여, **한국어 유니코드(UTF-8) 환경에서도 깨짐이나 꼬임 없이 완벽하게 사전순(ㄱㄴㄷ)으로 정렬**되어 가공 출력되도록 구현했습니다.

### ② 복합 데이터 통계 분석 및 외부 독립 CSV 리포트 추출 (11번 메뉴)
* 메모리상에 적재된 데이터를 실시간 연산하여 전체 평균 평점 및 장르별 평균 평점을 계산합니다.
* 연산 과정에서 `std::map` 자료구조와 C++17 구조적 바인딩(`structural binding`)을 활용하여 데이터 매핑 효율을 극대화했습니다.
* 분석된 핵심 지표와 평점 상위 Top 10 영화 목록을 **`stats.csv`라는 완전히 독립된 복합 파일 보고서 규격으로 자동 추출(Export)**해내는 파일 I/O 고도화를 달성했습니다.
